# E-Business Learning Hub 📚

Website pembelajaran statis untuk mata kuliah **E-Bisnis** yang dirancang dengan tampilan simple, elegan, dan profesional.

## 📋 Deskripsi

Website ini berisi materi pengenalan E-Business yang mencakup:
- Pengertian E-Business
- Perbedaan E-Business dan E-Commerce
- Model-model E-Business (B2B, B2C, C2C, C2B)
- Digital Payment
- Digital Marketing
- Keamanan dan Etika E-Business
- Contoh implementasi E-Business di Indonesia

## 🛠️ Teknologi yang Digunakan

- **HTML5** - Struktur halaman
- **Tailwind CSS** (via CDN) - Styling dan responsivitas
- **Vanilla JavaScript** - Interaktivitas dasar
- **Google Fonts** - Font Inter

## 📁 Struktur Folder


## 🚀 Cara Menjalankan

1. **Download/Clone** project ini ke komputer Anda
2. **Buka file `index.html`** langsung di browser (Chrome, Firefox, Edge, dll.)
3. Website siap digunakan! Tidak perlu server atau instalasi apapun.

### Menggunakan Live Server (Opsional)
Jika menggunakan VS Code:
1. Install extension **Live Server**
2. Klik kanan pada `index.html`
3. Pilih **"Open with Live Server"**

## ✏️ Cara Mengedit Informasi Mahasiswa

Buka file `index.html` dan cari bagian footer (di bagian bawah file), lalu ubah:
- Nama mahasiswa
- NIM mahasiswa

```html
<p class="text-white font-medium">Ahmad Izzuddin Azzam</p>
<p class="text-primary-400 text-sm">NIM: 2300492</p>
```
